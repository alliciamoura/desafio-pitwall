# 🏎️ PIT WALL – GP de São Paulo

## 📋 Sobre o Projeto

O **PIT WALL** é um projeto de desenvolvimento web criado como atividade prática de HTML5 e CSS3. O objetivo foi desenvolver uma página inspirada em um site de divulgação de eventos de Fórmula 1, utilizando como tema o Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

A página apresenta um visual moderno e esportivo, com predominância das cores preto, vermelho e branco, inspirado na identidade visual do automobilismo.

## 🎯 Objetivo

Praticar os conhecimentos de HTML e CSS, trabalhando com estruturação de páginas, organização de elementos, estilização, tabelas, formulários e layouts utilizando Grid e Flexbox.

## 💻 Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo da página.
- **CSS3:** Estilização, cores, fontes, espaçamentos, layouts e responsividade.
- **Visual Studio Code:** Editor utilizado para desenvolver o projeto.

## ⚙️ Estrutura da Página

O site foi dividido em algumas seções principais:

### 🏁 1. Cabeçalho e Banner Principal
- Logo PIT WALL.
- Menu de navegação.
- Botão para comprar ingresso.
- Banner do GP de São Paulo.
- Informações sobre voltas, quilômetros e curvas da pista.

### 🏎️ 2. Grid de Pilotos
- Apresentação de quatro pilotos.
- Números dos carros.
- Nomes dos pilotos.
- Identificação das equipes.

### 🏆 3. Classificação
- Tabela com as posições dos pilotos.
- Equipes, vitórias e pontuação.
- Campo de pesquisa e filtro visual.

### 🎟️ 4. Ingressos
- Apresentação dos setores e preços.
- Formulário para preenchimento de dados.
- Seleção de setor e data.
- Quantidade de ingressos.
- Campo para envio de foto.
- Espaço para mensagem ao piloto.

### 📌 5. Rodapé
- Identificação do projeto e informações complementares.

## 🎨 Identidade Visual

O projeto utiliza uma identidade visual inspirada no automobilismo:

- 🔴 Vermelho: velocidade, energia e destaque.
- ⚫ Preto: elegância e visual esportivo.
- ⚪ Branco: contraste e legibilidade.

## 📱 Responsividade

Foram utilizados recursos de CSS para adaptar a organização dos elementos a diferentes tamanhos de tela, como computadores, tablets e celulares.

## ⚠️ Observação

Este projeto é exclusivamente front-end. Portanto, os botões, filtros e formulário possuem finalidade visual e demonstrativa, não realizando operações reais de compra ou reserva de ingressos.

## 📚 Aprendizados

Durante o desenvolvimento da atividade, foi possível praticar a criação de layouts, utilização de classes, organização de seções, estilização de tabelas e formulários e aplicação de recursos de responsividade com HTML e CSS.
